# 知纲空首页落地页与 MinerU 自动解析设计

日期：2026-07-15

## 1. 背景与目标

当前首页在存在知识数据时会展示可交互的知识宇宙，但在没有课件或课程尚未生成知识点时，只显示品牌、服务配置和“添加课件”按钮。视觉氛围成立，但对首次访问者而言过于简单，无法解释知纲是什么、能产出什么以及知识宇宙如何形成。

本轮改动包含两个彼此独立、但共同改善首次使用体验的任务：

1. 为无知识数据状态增加完整的“编辑式天文台”落地页。
2. 简化课件预览到 MinerU 的流程，使“进入 MinerU 解析”真正开始解析，不再要求用户进入下一页后再次点击。

## 2. 范围

### 2.1 包含

- 无知识数据首页的完整产品介绍、能力说明、工作流程、知识宇宙机制和行动入口。
- 首页“全库知识问答”入口与能力说明。
- 固定暗星云背景、章节进入动画、移动端单列布局与减少动态效果适配。
- 有知识数据时继续显示现有交互式知识宇宙。
- 已配置 MinerU 时，从课件预览页一键开始解析。
- 未配置 MinerU 时，保存配置后自动续接解析。
- 对自动解析、取消、失败与重复触发的回归测试。

### 2.2 不包含

- 改造有知识数据时的知识宇宙布局、星云聚类或 Canvas 交互。
- 新增登录、云同步、服务端密钥托管或营销数据统计。
- 自动开始后续知识结构生成；MinerU 完成后仍由用户检查结果，再确认提取知识结构。
- 解析失败自动重试。

## 3. 用户状态与页面行为

首页继续以 `nebulaSummaries.some(summary => summary.knowledgeCount > 0)` 判断是否存在知识数据。

### 3.1 无知识数据

展示完整滚动式落地页。课程存在但知识点数量仍为零时，也属于此状态。

页面使用固定的暗马头星云作为全局背景；内容在其上滚动。用户可以从首页进入课件库、添加第一份课件、查看工作流程或进入全库知识问答。

### 3.2 有知识数据

不展示落地页章节，保持现有交互式知识宇宙、课程星云、缩放、拖拽、边缘移动、课件库入口与全库知识问答入口。

## 4. 首页信息架构

### 4.1 顶部导航

- 左侧：放大的“知纲”项目标识。
- 右侧：进入课件库、全库知识问答、服务配置。
- 移动端允许隐藏文字较长的次级导航，但主行动保持可见。

### 4.2 首屏

- 英文眉题：`FROM COURSEWARE TO KNOWLEDGE`
- 主标题：`让每一份课件，成为可探索的知识宇宙。`
- 产品介绍：知纲把分散的课件转化为知识结构、知识卡片、完整笔记和可追溯问答。
- 主行动：`添加第一份课件`，进入课件库。
- 次行动：`全库知识问答`，进入全库问答。
- 文本位于左侧，右侧保留星云主体和负空间。

### 4.3 核心能力

使用编辑式分栏而不是常规等宽卡片墙，展示四项能力：

1. 知识结构：从章节与课件证据中识别概念及关系。
2. 知识卡片：把复杂内容整理为可复习、可检索的知识单元。
3. 完整笔记：围绕课程结构生成连续、可阅读的知识文档。
4. 全库知识问答：跨课程检索并将回答追溯到原始课件。

### 4.4 工作流程

使用三步横向流程，移动端改为纵向：

1. 导入 PDF、PPTX 或 Markdown 课程材料。
2. 解析、提取并组织课程知识。
3. 在知识宇宙、笔记、卡片和问答中持续探索。

### 4.5 知识宇宙机制

解释产品隐喻，但不把它写成空状态提示：一门课程聚成一团星云，每个被课件证据支持的知识点成为一颗亮星。知识越丰富，星云越绚烂。

### 4.6 最终行动区

- 标题：`你的知识宇宙，等待第一次观测。`
- 主行动：创建课程或添加课件。
- 次行动：进入全库知识问答。
- 页脚保留简洁项目标识，不增加营销链接集合。

## 5. 视觉设计

设计方向为“编辑式天文台”：把天文观测报告的克制排版、深空影像和现代知识产品结合起来。

- 背景：复用现有 `dormant` 马头星云素材，固定在视口，不随章节切换图片。
- 可读性：图片上叠加暗色洗层和边缘渐晕；正文区域使用局部半透明深色表面，避免整页玻璃卡片。
- 字体：中文标题继续使用宋体体系；英文标签和编号使用等宽字体；正文使用现有 UI 字体。
- 色彩：冷青色用于导航和知识能力，暖红色只作为星云与少量强调，不与主按钮争夺注意力。
- 空间：首屏采用左文右景的非对称构图；章节之间使用充足负空间、细分隔线和编号建立节奏。
- 动效：章节进入视口时淡入并上移 12–20px；背景只做极轻微视差或亮度变化。
- 无障碍：`prefers-reduced-motion: reduce` 时取消视差和位移动画；背景保持 `aria-hidden` 与 `pointer-events-none`。

## 6. 响应式行为

- 桌面端：首屏保留星云主体；核心能力使用编辑式多栏；工作流程横排。
- 平板：减少标题尺寸和章节间距，能力区改为两列。
- 移动端：单列内容，主操作按钮可换行或占满宽度；星云焦点上移；不出现横向滚动。
- 移动端导航至少保留项目标识、添加课件和服务配置；全库知识问答可放入首屏操作区而不重复占用顶部空间。

## 7. 组件设计

### 7.1 `DormantHomeLanding`

新增独立组件，负责：

- 固定星云背景上的完整落地页结构。
- 首页导航、首屏、四项能力、三步流程、知识宇宙机制与最终行动区。
- 触发课件库、全库问答、服务配置和页内锚点导航。
- 章节进入动画与减少动态效果适配。

它不读取或修改课程数据，只通过回调触发导航。

### 7.2 `HomeView`

继续负责读取 `nebulaSummaries` 并区分两种首页状态：

- 无知识数据：渲染 `DormantHomeLanding`。
- 有知识数据：渲染现有知识宇宙界面。

### 7.3 `DocumentReviewWorkspace`

扩展“进入 MinerU 解析”动作：

- Markdown：调用现有 `startMinerUParse()`，直接进入已完成的 MinerU 状态。
- PDF/PPTX 且已配置：导航到 `mineru` 并立即调用 `startMinerUParse()`。
- PDF/PPTX 且未配置：请求 App 打开带“解析续接意图”的设置弹窗。

按钮执行期间禁用，避免短时间内重复启动同一个解析任务。

### 7.4 `SettingsModal` 与 `App`

`App` 使用仅存在于当前 UI 会话的临时状态记录 `resumeMinerUParseAfterSettings`。该状态不写入持久化存储。

当设置弹窗由 MinerU 解析入口打开时：

- 保存按钮显示为“保存并开始解析”。
- MinerU endpoint 或 Token 为空时不关闭弹窗，并显示校验提示。
- 保存成功后，先写入配置，再清除临时意图、关闭弹窗、导航到 `mineru`，最后调用 `startMinerUParse()`。
- 取消或关闭弹窗会清除临时意图并保留在课件预览页。

普通服务配置入口不改变现有保存行为。

## 8. MinerU 状态流

### 8.1 已配置

`课件预览` → 点击“进入 MinerU 解析” → `mineru` 页面 → `startMinerUParse()` → 实时进度 → 完成或失败。

### 8.2 未配置

`课件预览` → 点击“进入 MinerU 解析” → 服务配置弹窗 → 保存有效配置 → `mineru` 页面 → `startMinerUParse()`。

用户取消时回到课件预览，不开始解析。

### 8.3 错误与幂等

- 缺少源文件：进入 MinerU 页面并显示现有“找不到原始课件文件”错误。
- API 配置无效：在设置弹窗内阻止续接，不调用解析。
- API 请求失败：停留在 MinerU 页面，显示格式化错误和“重新解析”。
- 正在运行时再次点击相关按钮不会创建第二次请求。
- 自动续接意图在成功触发、取消或关闭弹窗后必须清除，避免后续普通保存意外启动解析。

## 9. 测试与验收

### 9.1 首页

- 无知识数据时存在主标题、产品介绍、四项能力、三步流程和最终行动区。
- “添加第一份课件”进入课件库。
- “全库知识问答”进入问答页。
- 页面不再只有一个按钮，也不出现旧的“没有课件/没有星云”解释性空状态。
- 有知识数据时不渲染落地页，并保留原知识宇宙控制和入口。
- 背景保持不可交互；移动端关键按钮可见且无横向溢出。

### 9.2 MinerU

- 已配置时，预览页按钮调用解析一次并进入 MinerU 页面。
- Markdown 不要求 MinerU 配置，直接进入已完成状态。
- 未配置时打开设置弹窗，不立即调用解析。
- 有效配置保存后自动续接一次。
- 无效配置不能关闭续接弹窗，也不能调用解析。
- 取消设置不调用解析，并清除续接意图。
- 快速重复点击不会提交多个解析请求。
- 失败后不自动重试，用户可以手动重新解析。

### 9.3 回归验证

- 运行首页、导航、设置、课件预览和 MinerU 的聚焦测试。
- 运行完整 Vitest 测试集、TypeScript 检查、ESLint 和生产构建。
- 在桌面与 390px 移动视口检查首屏、全部章节、固定背景、入口可达性和滚动行为。

## 10. 完成标准

- 首次访问者无需已有课件，也能从首页理解知纲的定位、核心产物、工作流程和知识宇宙机制。
- 全库知识问答在首屏、核心能力和最终行动区都有清晰入口或说明。
- 页面仍然以真实暗星云和项目内容为主，不退化为常规 SaaS 卡片墙。
- 有知识数据的用户继续获得现有交互式知识宇宙。
- 从课件预览点击 MinerU 后不再需要在下一页再次点击“开始解析”。
- 未配置服务时，配置成功可以无缝续接；取消、无效配置和错误状态不会误触发解析。
