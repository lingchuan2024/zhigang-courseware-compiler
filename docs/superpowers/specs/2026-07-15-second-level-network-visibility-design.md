# 二级知识网络可见性修复设计

## 背景

从一级课程知识节点进入二级知识网时，界面仍把父级节点 ID 作为 `selectedId` 传给二级画布。该 ID 不存在于二级网络，导致所有二级节点都被判定为非关联节点：节点透明度降为 `0.32`，关系边透明度降为 `0.08`。页面因此整体变暗。

## 目标

- 初次进入二级知识网时，所有二级节点以正常亮度显示。
- 父级知识点仍保持为原文面板的当前上下文，不丢失父级来源信息。
- 用户选中某个二级节点后，只弱化与该节点无关的节点和关系。
- 一级知识网的选中、搜索、关系筛选与缩放行为保持不变。

## 方案

在 `KnowledgeStructureView` 中区分“内容上下文选中项”和“当前画布有效选中项”。

`selectedNodeId` 继续用于查找原文面板内容；新增派生值 `canvasSelectedNodeId`：仅当 `selectedNodeId` 存在于 `currentNetwork.nodes` 中时才传给 `KnowledgeNetworkCanvas`，否则传入 `null`。

因此，点击一级节点进入二级知识网后：

1. `selectedNodeId` 仍指向父级节点，右侧原文面板继续显示父级来源。
2. `canvasSelectedNodeId` 为 `null`，二级画布不会进入错误的弱化状态。
3. 点击任一二级节点后，两者都指向该二级节点，画布恢复正常的邻域高亮行为，原文面板同步切换。

关系边在无选中项时的基础透明度从 `0.2` 提升到 `0.34`，让方向关系在深色背景上可辨，同时仍弱于节点主体。存在有效选中项时，关联边保持高亮，非关联边保持弱化。

## 边界与异常

- 二级网络为空时继续使用现有空状态，不自动选择任何节点。
- 搜索与关系筛选仍在当前层内生效。
- 父级节点被删除或网络数据更新失效时，沿用现有 effect 清空展开和选中状态。
- 不自动选择第一个二级节点，避免未经用户操作就切换原文面板。

## 测试

- 组件测试：父级 ID 不属于二级网络时，传给画布的有效选中项为空，所有二级节点透明度为 `1`。
- 组件测试：无有效选中项时，关系边使用可辨识的基础透明度。
- 组件测试：选中二级节点后，选中节点与邻居保持高亮，无关节点才被弱化。
- 回归测试：进入二级网后父级原文仍可见；点击二级节点后原文正确切换；收起后一级网恢复。

## 非目标

- 不调整知识网络布局算法。
- 不改变节点配色体系或知识数据生成逻辑。
- 不自动选择二级节点。
