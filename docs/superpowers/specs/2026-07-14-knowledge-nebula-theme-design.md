# 知纲全站知识星云主题设计

## 1. 目标与范围

本次改造将“知纲”从米白、墨绿的纸张式界面升级为深空知识观测站。首页使用由真实课程和知识数据生成的动态星云背景；课件库、处理工作流、知识结构、知识卡片、完整笔记和全库问答统一迁移到稳定、克制的深色界面。

本设计已经确认以下原则：

- 星空只作为背景和空间隐喻，不把整站做成持续晃动的 3D 场景；
- 首页不展示装饰性知识连线；
- 同一门课程的知识点聚集成一团星云；
- 课件中真实识别出的知识点才产生亮星，未知知识不预先绘制；
- 知识点越多，星云中的亮星越多，星云也更大、更丰富；
- 用户数量未知，因此布局必须根据课程数、课件数和知识点数动态生成；
- 首页星云空间可以大于视口，支持滚轮、按钮、触控缩放以及边缘平移；
- 首页保留明显的项目名称“知纲”，但不恢复已否决的顶部导航、在线状态、坐标和“当前观测”统计；
- 全站采用深色主题，但 PDF、PPTX 原始课件页面保持原色；
- 色彩参考真实天文图像的氧、氢、氮、硫和尘埃层次，但明确属于数据驱动的视觉映射，不宣称为天体的肉眼真实颜色。

## 2. 产品隐喻

```text
全部知识库   → 尚在扩展的知识宇宙
课程空间     → 一团课程星云
一份课件     → 一次观测与证据曝光
独立知识点   → 星云中的亮星
重复课件证据 → 更稳定、更明亮的星核
知识卡片完成 → 星体外层形成清晰光晕
未识别知识   → 不绘制，不伪造暗星
```

系统不预设完整宇宙。没有课程时只有深空；新增课程时形成新的星云；新增课件时，同一课程星云增加知识星或增强已有星体；删除课件后，没有其他证据支撑的知识星熄灭并从摘要中移除。

## 3. 首页视觉设计

### 3.1 构图

首页由两个独立层组成：

```text
HomeView
├── KnowledgeNebulaBackground
│   ├── 深空底色与远景恒星
│   ├── 课程星云气体与尘埃
│   ├── 真实知识亮星
│   └── 视野平移与缩放
└── HomeForeground
    ├── 项目标识“知纲”
    ├── 核心标题与说明
    ├── 进入课件库 / 探索知识宇宙
    └── 课程、课件和知识统计
```

背景负责沉浸感，前景负责产品表达。前景不使用顶部导航条，不显示英文在线状态、坐标、观测序号或单独的“当前课程星云”信息块。

### 3.2 项目标识

- “知纲”固定在左上角，桌面端字号为 36–44px，移动端为 28–32px；
- 使用现有中文衬线标题字体，保持学术气质；
- 可配一行很小的 `KNOWLEDGE NEBULA`，但不得抢占主标题层级；
- 标识独立悬浮，不使用整条导航背景或分隔线。

### 3.3 星云形态

每个课程星云必须具有不规则轮廓，不能画成同心圆、均匀椭圆或规则旋涡。星云由四类视觉元素叠加：

1. 大尺度低透明气体云，形成课程区域；
2. 沿不规则弧线和湍流分布的细小尘埃；
3. 黑色或近黑色遮挡带，模拟密集星际尘埃；
4. 由真实知识数据生成的亮星。

不同课程使用不同的确定性形态种子和色彩组合，但仍属于同一视觉系统。重新进入首页时，同一课程保持相近位置、轮廓和颜色，避免用户每次看到完全不同的宇宙。

### 3.4 星云色彩

色彩参考 NASA 和 ESA 的天文图像处理原则：短波或氧离子区域常映射为蓝、青色，较长波段和部分氮、硫区域映射为橙、红色，尘埃可呈现金褐、锈色和深色遮挡。

预设色组如下：

| 色组 | 冷色气体 | 发射区域 | 尘埃与过渡 |
|---|---|---|---|
| Oxygen–Hydrogen | `#2E6DA8` | `#A62E46` | `#B67445` |
| Teal–Sulfur | `#1D7E8B` | `#B9302B` | `#873973` |
| Cobalt–Dust | `#345D9C` | `#B24830` | `#B9854B` |
| Violet–Flame | `#5D569F` | `#9F314B` | `#C08A5A` |

颜色只用于星云气体和少量状态，不把红色、紫色铺到按钮、正文和所有边框上。所有气体颜色以低透明度叠加，保留黑色空间和明暗层次，禁止高饱和霓虹描边。

参考来源：

- [NASA：Webb 全彩图像如何生成](https://science.nasa.gov/mission/webb/science-overview/science-explainers/how-are-webbs-full-color-images-made/)
- [NASA：Bubble Nebula 的气体颜色](https://science.nasa.gov/asset/hubble/mosaic-image-of-the-bubble-nebula/)
- [ESA：Carina Nebula 中硫、氢、氧的颜色映射](https://sci.esa.int/web/hubble/-/40915-extreme-star-birth-in-carina-nebula)

## 4. 数据模型与生成规则

### 4.1 轻量首页摘要

首页不得逐份加载完整 Markdown、课件页和图片。新增可持久化的轻量摘要：

```ts
interface KnowledgeNebulaSummary {
  version: 1;
  generatedAt: number;
  courses: CourseNebulaSummary[];
}

interface CourseNebulaSummary {
  courseId: string;
  courseName: string;
  documentCount: number;
  knowledgeCount: number;
  completedCardCount: number;
  updatedAt: number;
  paletteId: string;
  seed: number;
  stars: KnowledgeStarSummary[];
}

interface KnowledgeStarSummary {
  key: string;
  name: string;
  sourceDocumentCount: number;
  evidenceCount: number;
  importance: 'core' | 'important' | 'supplementary';
  cardStatus: 'none' | 'partial' | 'complete' | 'failed';
}
```

### 4.2 摘要来源

- 课程来自 `LibraryCourse`；
- 课件元数据来自 `LibraryDocument`；
- 具体知识点来自各课件快照中的 `knowledgeTopics`；
- 卡片完成状态来自 `knowledgeCards`；
- 同一课程内以规范化后的知识名称和别名合并视觉星体；
- `sourceDocumentCount` 表示多少份课件共同出现该知识；
- `evidenceCount` 来自知识主题绑定的来源范围或卡片证据数量。

快照保存、知识结构更新、卡片更新、课件删除和课程删除后，重新计算受影响课程的摘要。旧数据没有摘要时，首页在后台惰性生成；单份课件损坏不能阻断其他课程星云。

### 4.3 数量映射

每个课程知识点原则上对应一颗亮星。为控制性能，使用分级细节：

- 1–40 个知识点：逐颗绘制全部亮星；
- 41–120 个知识点：全部保留星光，但只有核心和高重要度星体拥有较大光晕；
- 超过 120 个知识点：保留 120 颗独立亮星，其余数量转化为更密集的小型星簇和更高的气体亮度；
- 首页全局最多绘制 600 颗独立知识亮星，其余通过课程级星簇表现；
- 课程星云面积按 `sqrt(knowledgeCount)` 增长，并设置最小与最大半径；
- 星云背景尘埃数量随知识点数量增长，但设置设备性能上限。

因此，知识点更多的课程必然拥有更多亮星和更饱满的星云，但不会因为极端数据量导致浏览器失速。

### 4.4 亮度语义

- 是否绘制：知识是否被真实课件识别；
- 基础亮度：该知识是否存在；
- 亮度增强：同一知识被更多课件共同支撑；
- 星体尺寸：知识重要度；
- 清晰外光晕：知识卡片已经生成；
- 暗橙或红色边缘：生成失败或数据异常；
- 不使用亮度表达用户掌握程度，因为当前项目没有可靠的掌握度数据。

## 5. 首页交互

### 5.1 平移

- 当世界尺寸大于视口时，鼠标进入屏幕边缘 80–100px 区域，视野按距离边缘的程度平滑移动；
- 视野速度缓慢增加，不突然跳动；
- 离开边缘区域后自然减速；
- 视野不能越过宇宙边界；
- 触屏设备使用单指拖动，不使用边缘感应。

### 5.2 缩放

- 鼠标滚轮围绕光标位置缩放；
- 提供简洁的 `− / 百分比 / +` 控件；
- 提供“适应全部星云”入口，防止用户迷失；
- 桌面端缩放范围为 60%–180%；
- 触屏支持双指缩放；
- 缩放与平移使用同一相机状态，采用缓动插值；
- `prefers-reduced-motion` 下移除惯性和自动缓动，但保留即时缩放和平移功能。

### 5.3 点击与导航

星云在首页属于背景，不把每颗知识星做成按钮。仅课程星云整体提供可选的点击热区：

- 悬停星云时显示课程名称、课件数和知识点数；
- 点击星云进入对应课程空间；
- 不在首页展示关系连线或知识详情面板；
- 知识点级交互保留在专门的知识结构页面。

现有 `paper`、`ink`、`celadon` 等 Tailwind 名称可以在迁移期映射到新语义色，但新组件使用明确的空间语义变量。禁止继续新增米白色硬编码。

### 6.2 页面策略

- 首页：完整动态知识星云背景；
- 课程库：静态深空背景，课程与课件使用低透明深蓝档案面板；
- 工作流侧栏：深蓝观测导航，当前步骤使用青色小型状态光，不使用大面积发光；
- 课件预览：工具栏和外围工作区深色，PDF/PPTX 页面保持原始颜色；
- MinerU 解析：深色编辑器与预览，文本对比度优先；
- 知识结构：保留功能性关系线，但默认低透明，仅在选中或悬停时突出；全局背景不出现关系线；
- 知识卡片：深蓝知识档案面板，正文不发光；
- 完整笔记：静态深色阅读背景，Markdown、表格、代码和公式均使用高对比主题；
- 全库问答：采用深色探索日志，不使用满屏气泡或动画星云；
- 设置和确认弹窗：深色实体面板，危险操作继续使用克制红色。

### 6.3 动画边界

- 只有首页 Canvas、页面切换和关键状态具有动画；
- 阅读、编辑、PDF/PPTX 预览区域不持续漂移；
- 不使用快速闪烁、弹跳、鼠标追随光球或大量同时运行的模糊动画；
- 星云只做极轻微的亮度呼吸，课程布局本身不持续旋转。

## 7. 组件与模块边界

```text
src/components/nebula/
├── KnowledgeNebulaBackground.tsx  # Canvas 生命周期与绘制入口
├── NebulaViewportControls.tsx     # 缩放、适应视图和提示
├── NebulaCourseHotspots.tsx       # 课程悬停与导航热区
└── ProjectMark.tsx                # 放大的“知纲”标识

src/lib/nebula/
├── nebula-summary.ts              # 从课程、课件快照生成摘要
├── nebula-layout.ts               # 确定性课程布局与边界计算
├── nebula-scene.ts                # 星云、尘埃和知识星绘制数据
├── nebula-camera.ts               # 平移、缩放和边缘移动纯函数
└── nebula-performance.ts          # DPR、粒子数和降级等级
```

Canvas 绘制逻辑不写进 `HomeView.tsx`。布局、相机和摘要生成保持纯函数，便于单元测试。React 不参与每一帧粒子更新。

## 8. 渲染与性能

- 全站只在首页运行一个 Canvas；
- 静态星云气体和尘埃优先绘制到离屏 Canvas，动画帧只处理相机、少量星光变化和合成；
- `devicePixelRatio` 桌面端上限为 1.6，低性能设备降到 1；
- 页面隐藏时取消 `requestAnimationFrame`；
- `ResizeObserver` 或窗口 resize 后重新计算尺寸和相机边界；
- 卸载组件时取消动画、移除滚轮、指针和可见性监听；
- 移动端减少 50%–70% 尘埃粒子，降低模糊半径，禁用边缘移动；
- `prefers-reduced-motion` 下使用静态星云，并保留按钮缩放、拖动和课程导航；
- 首页摘要或星云构建失败时显示深空渐变和现有首页内容，不阻断课程库入口。

## 9. 空状态与异常状态

### 没有课程

只显示安静深空、稀薄尘埃和“导入第一份课件”入口，不伪造课程星云和知识星。

### 有课程但没有课件

显示非常暗、尚未成形的气体云，不显示亮星；课程名称仍可进入课程空间。

### 有课件但没有知识结构

显示低亮度星云尘埃，状态为“等待知识观测”；不根据页数伪造知识星。

### 部分课件读取失败

继续绘制其他课程和课件；失败课程使用深色星云并在悬停信息中提示部分数据未加载。

### Canvas 不可用

回退到静态 CSS 深空渐变和课程统计，所有导航功能仍可使用。

## 10. 可访问性

- Canvas 标记为装饰性背景，并提供简短替代描述；
- 课程星云的点击热区使用真实按钮和课程名称；
- 键盘可以依次聚焦课程星云，Enter/Space 进入课程；
- 缩放按钮有明确 `aria-label` 和可见焦点；
- 不通过颜色单独表达失败或完成状态；
- 主文字与背景保持 WCAG AA 可读对比度；
- 减少动态效果后仍能访问全部功能；
- 移动端触控目标不小于 44px。

## 11. 测试与验收

### 数据测试

- 课程、课件和知识主题正确生成星云摘要；
- 同一课程内规范化后的重复知识合并为同一视觉星体；
- 新增和删除课件后亮星数量正确变化；
- 删除课程后对应星云消失；
- 旧快照可以惰性生成摘要；
- 单课件损坏不影响其他课程摘要。

### 布局与相机测试

- 相同 ID 和摘要生成稳定布局；
- 不同课程星云不会完全重叠；
- 极少和极多知识点都能正确计算星云范围；
- 缩放围绕光标位置保持锚定；
- 相机不能越过世界边界；
- 边缘移动速度连续且可停止；
- 适应视图能找回所有课程星云。

### 组件与回归测试

- 首页显示放大的“知纲”标识；
- 首页不再显示顶部导航、在线状态、坐标和“当前观测”统计；
- 点击课程星云进入正确课程；
- 无课程、无知识、失败和 Canvas 降级状态正确；
- PDF/PPTX 原始页面颜色不被反转；
- Markdown、KaTeX、表格、代码块和弹窗在深色主题下清晰；
- 现有课程库、课件处理、知识卡片、笔记和问答功能保持原行为。

### 性能验收

- 桌面端常见设备在首页保持流畅平移和缩放；
- 600 颗独立知识亮星下交互无明显卡顿；
- 页面离开后台后动画停止；
- 移动端降级后保持可操作；
- 类型检查、生产构建和项目测试通过。

## 12. 分阶段实施

### 阶段一：主题基础与首页星云

1. 建立全局语义色和基础组件主题；
2. 建立星云摘要、确定性布局和 Canvas 渲染；
3. 实现边缘平移、滚轮/按钮缩放、适应视图和移动端拖动；
4. 改造首页前景、项目标识、空状态和课程导航；
5. 改造 AppShell、课程库和通用弹窗。

### 阶段二：工作流页面迁移

1. 工作流侧栏和上传页；
2. PDF/PPTX 预览与 MinerU 解析；
3. 知识结构与功能性关系线；
4. 知识卡片与完整笔记；
5. 全库问答与设置弹窗；
6. 全站视觉回归和性能验证。

每个阶段结束时必须保持项目可构建、可测试和功能可用，避免出现深浅主题混杂导致的文字不可读状态。

## 13. 非目标

本次不实现知识掌握度评估、账号云同步、多人共享宇宙、背景音效、全站 Three.js 3D 场景、复杂物理粒子模拟或游戏化航行。首页采用 Canvas 2D 与确定性生成，优先保证真实数据映射、视觉品质、性能和长期可维护性。
