# 双层知识网交互设计

## 目标

把“知识结构”从目录和卡片详情改为真正的双层网络：第一层展示课程核心知识及其关系；进入某个核心知识后，第二层展示其内部讲解内容及关系。无论位于哪一层，点击节点都能在右侧看到该节点引用的 MinerU Markdown 原文。

## 当前问题

新版 Markdown 管线生成了 `KnowledgeTopic`、`TopicRelation`、`TeachingBlock` 和 `TeachingRelation`，但 `KnowledgeStructureView` 只显示列表、线性学习路径和卡片详情。旧版 `KnowledgeGraph` 虽能画第一层网络，却读取旧数据结构，并且第二层仍以列表呈现。结果是“数据中存在关系，界面上看不到网”。

## 页面结构

知识结构页采用三段式布局：

1. 顶部工具栏：返回、面包屑、搜索、关系筛选、推荐路径开关、适应画布和查看笔记。
2. 中央网络画布：占据主要空间，负责展示当前层的节点与边，支持缩放、平移、适应画布和键盘选择。
3. 右侧原文面板：默认宽度 360px；选择节点后显示节点信息、来源区间和对应原文。面板可以折叠，但选择节点时自动展开。

顶层面包屑为：

```text
课程知识网
```

进入某个知识后变为：

```text
课程知识网 / 最大似然估计 / 内部结构
```

点击“课程知识网”返回第一层，并保留之前选中的课程节点和画布位置。

## 第一层：课程知识网

- 节点来源：`knowledgeTopics`。
- 边来源：`topicRelations`。
- 节点主要文字：知识名称；辅助信息只保留重要性、难度和来源数量，避免节点过宽。
- 边显示关系类型，包括硬前置、建议先学、派生、组成、应用、扩展、对比和并列。
- 单击节点：选中并在右侧显示该知识的 `sourceRanges` 原文。
- 双击节点或点击节点浮层中的“查看内部结构”：进入该知识的第二层网络。
- 开启“推荐学习路径”后，仅在现有网络上高亮 `courseLearningPath` 的连续路线，不隐藏或改写原始关系。
- 搜索时命中节点高亮，其他节点降低透明度；不从网络中删除节点，避免布局跳动。

## 第二层：知识点内部网

- 节点来源：当前 topic 的 `teachingBlocks`。
- 边来源：当前 topic 的 `teachingRelations`。
- 节点文字：讲解块标题；辅助标签为动机、定义、公式、推导、案例、条件、误区等讲解类型。
- 单击节点：在右侧显示该讲解块 `sourceRanges` 对应的原文。
- 教学推荐顺序来自 `TopicNarrativePath.orderedTeachingBlockIds`，作为可开关的高亮路线，不替代内部关系网。
- 没有关系但存在讲解块时仍显示全部节点，并在画布上提示“当前仅提取到内容节点，尚无内部关系”，不能退化回列表。
- 当前知识没有讲解块时显示明确空状态，并提供返回第一层的按钮。

## 右侧原文面板

右侧面板只展示与当前选中节点直接相关的内容：

1. 节点名称、节点类型、置信度和关系数量。
2. 来源文档名称和 Markdown 标题路径。
3. 每个 `SourceRange` 对应的连续原文块，按文档顺序排列。
4. “渲染预览 / 原始 Markdown”切换；默认显示渲染预览，原始模式保留公式、表格和图片引用语法。
5. 多个不连续来源区间分别显示，不把它们拼成一段伪造的连续原文。

来源解析规则：根据 `SourceRange.documentId` 找到 `SourceDocument`，再从 `startBlockId` 到 `endBlockId` 读取连续 `MarkdownBlock`。找不到来源时显示“该节点缺少可定位原文”，并列出缺失的范围标识；不能使用摘要或 AI 笔记冒充原文。

## 视觉规则

- 继续沿用当前墨绿、米白和朱红配色，不引入新的视觉体系。
- 第一层节点按重要性区分边框和强调程度，按知识类型显示小型文字标签。
- 第二层节点按讲解类型分成少量颜色族：概念说明、数学推导、方法步骤、案例应用、限制纠错。
- 选中节点使用深色描边和轻微外发光；其一跳邻居保持正常，其余节点降至约 35% 透明度。
- 边标签只在选中边或较高缩放级别显示，避免整张网被文字覆盖。
- 图例根据当前实际出现的关系类型动态生成。

## 组件边界

- `KnowledgeStructureView`：管理当前层、选中节点、面包屑和工具栏状态。
- `KnowledgeNetworkCanvas`：通用 SVG 网络画布，只接收标准化节点、边和交互回调。
- `knowledge-network-adapter`：把课程知识和讲解结构分别转换成统一的图节点/图边，并生成推荐路径边。
- `SourceEvidencePanel`：根据节点携带的 `SourceRange[]` 解析和显示原文。
- `source-range-resolver`：纯函数，将来源范围转换为按顺序排列的 Markdown 块和缺失信息。

网络画布不直接读取 Zustand store，原文面板不负责改变图状态，从而保证两层共用同一套交互并能独立测试。

## 状态与异常处理

- 加载中：保留现有管线进度页，不提前渲染空画布。
- 无第一层节点：显示提取失败或空状态，不显示伪造示例网络。
- 有节点无关系：仍显示节点，并说明关系尚未提取。
- 来源范围缺失：右侧显示定位失败，不回退到 AI 摘要。
- 关系引用不存在节点：忽略该边并在工具栏显示数据警告数量。
- 大型网络：首次自动适应画布；缩放和平移只改变视口，不重复执行 AI 或修改知识数据。

## 可访问性

- 节点可通过 Tab 聚焦，Enter 选择，第二次 Enter 或明确的“进入内部结构”按钮执行钻取。
- 选中状态不能只靠颜色，同时使用描边、状态文字和 `aria-selected`。
- 工具栏按钮提供中文 `aria-label`，焦点样式满足可见性要求。
- 右侧原文面板打开后不强制抢走键盘焦点，保证用户可以连续浏览网络节点。

## 测试与验收标准

1. 进入知识结构页时默认看到第一层课程网络，而不是知识目录列表。
2. 每个 `KnowledgeTopic` 都对应一个节点，每个有效 `TopicRelation` 都对应一条边。
3. 点击第一层节点后，右侧只显示其 `sourceRanges` 对应的原始 Markdown。
4. 进入节点内部后，画布显示 `TeachingBlock` 与 `TeachingRelation` 组成的第二层网络。
5. 点击第二层节点后，右侧只显示该讲解块的原始 Markdown。
6. 面包屑能返回第一层，并恢复第一层选中节点。
7. 推荐学习顺序只作为高亮覆盖层，不改变或隐藏原始关系。
8. 多个来源范围分组显示；缺失范围不会由摘要或笔记替代。
9. 第一层和第二层都支持缩放、平移、适应画布、搜索和键盘选择。
10. 图适配、来源范围解析和层级导航具有自动化测试；完整测试、类型检查、构建和 lint 均无新增错误。

## 不在本次范围内

- 手工拖动节点并保存布局。
- 用户编辑或新增知识关系。
- 跨课件全局知识锚点网络。
- 在网络中直接编辑 MinerU 原文。

这些能力可以在双层网络稳定后单独设计，避免首版交互过重。
