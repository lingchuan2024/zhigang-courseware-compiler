## 第二轮：证据完整性与生成效率

真实运行发现 `topicsToCandidates` 将连续来源区间缩成首尾块，局部合并后的公式、例子与中间推导因此丢失。首跑只覆盖 19.79% 的原文块，尽管 57 张卡片均标为完成。修复后按同一文档展开完整区间，增加多次压缩、逆向区间和跨文档隔离的回归测试。

主题综合采用最多 3 个并发 worker，结果仍按学习顺序保存，章节写作仍按顺序运行。综合正文只输出到 `sections[].markdown`，章节输入不再重复携带同一正文的顶层 `markdown`；重试单章使用相同的精简输入。保留条件与 AI 补充标记，防止二次改写模糊材料边界。

529 项测试通过，类型检查、lint、生产构建通过。真实复跑沿用同一 MinerU 解析，从知识提取开始重跑。已验证原文覆盖从 56/283 块提升到 247/283 块（19.79% → 87.28%），卡片从 57 增至 102 张。

## 第三轮：成文质量与前端清理

首跑 23 个综合中 2 个降级，9 章中“矩阵的秩与满列秩”生成失败，共出现 6 个 `finish_reason=length` 响应。写作要求增加输出预算、跨卡片内容去重、公式使用数学分隔符、变量维度与常数因子复核，并要求所有补充整段放在引用块中。使用第二轮相同的 102 张卡片单独重跑笔记，以隔离知识提取变化。

前端移除 5 个重复按钮：空首页顶部的课件库/问答入口、底部重复的添加课件/问答按钮，以及侧栏的加载示例按钮（上传页保留示例入口）。已完成的笔记隐藏不必要的模型配置提示；未生成或有未完成章节时仍显示。课件库、服务配置、章节导航、原文依据、导出与重试均保留。

浏览器验收：示例课程可以打开完整笔记，依据抽屉正常展示引用卡片；空首页只保留一组添加课件/问答主入口。真实笔记在应用同一 MarkdownRenderer 中检查。

## 首跑内容评审

- 课件总解析时间 41.8 秒（含上传、轮询、下载）；全流程 826.6 秒，DeepSeek 150 次响应、613,064 token。
- 纯笔记阶段 497.1 秒、334,399 token。该数值来自原始 API 响应，包括截断重试；旧应用统计只有 232,297，少算 102,102 token。
- 生成 8/9 章，正文共 47,102 字符；完成标记不等于内容审核通过。
- 首跑把 SGD 的 `X_b`、`y_b` 解释为“增广”数据；恢复中间证据后，第二轮对应卡片已正确解释为“小批量数据”。
- 首跑把半平方损失与未除以二的梯度链混写；第二轮最小二乘卡片使用同一损失定义，保留可逆/满列秩条件，公式链一致。
- 首跑大量反复解释“本节点”“课程位置”，一些原文已有的推导被错误描述为“课件未提供”；证据范围修复减少了这一根源。
- 这是单一课件的抽样核验，未做每句话的独立事实评分。未覆盖块与课程总结/参考资料噪声仍需人工审阅；解析图片的语义没有单独核验。

## 最终实测对照

| 运行 | 运行范围 | 总耗时 | DeepSeek 总 token | 纯笔记耗时 | 纯笔记 token | 完成章节 |
|---|---|---:|---:|---:|---:|---:|
| 首跑 | PDF → MinerU → 知识 → 笔记 | 826.6 秒 | 613,064 | 497.1 秒 | 334,399 | 8/9 |
| 第二轮 | 复用解析，重跑知识与笔记 | 882.5 秒 | 961,091 | 417.1 秒 | 461,653 | 6/10 |
| 第三轮 | 复用第二轮相同卡片，仅重跑笔记 | 290.4 秒 | 377,158 | 290.3 秒 | 377,158 | 10/10 |

第三轮对第二轮同一组 102 张卡片，笔记耗时减少 **30.4%**、token 减少 **18.3%**，成文从 6/10 章提升到 10/10 章（58,637 正文字符）。相比首跑内容覆盖更多，不能直接用整流程 token 判定效率。三个运行累计 1,951,313 DeepSeek token，MinerU 不包含在该 token 口径内。每轮仅一次样本，运行有部分重叠，服务负载与模型采样会影响耗时和章节编排；这不是受控性能基准。

原始用量统计包括所有获得 usage 的响应（含截断重试）。首跑应用统计漏计，因此纯笔记 token 按首次 master-note 请求对应的原始响应起点汇总；后两轮已与修复后应用统计逐项核对。第三轮有 3 个截断响应：一个主题综合重试后降级，另一个章节重试成功。最终所有章节完成，但 **1/22 个主题综合仍采用卡片回退内容**，并非全流程零降级。

### 最终质量与边界

- 实际渲染发现 3 处同一行 `$$...\tag{n}$$` 被视为行内公式。已修复 Markdown 归一化并在渲染旧笔记时应用：只转换独立公式行，保留代码、行内公式和已有多行公式。新增实际 KaTeX 渲染与幂等回归测试。
- 浏览器最终复核：第三轮 74 个块级公式、0 个 KaTeX 错误、0 个代码块形式的公式。
- 最终 531 项测试全部通过；类型检查、lint、生产构建通过。仍有 11 项既有 lint 警告和大包构建提示。
- 原始生成文本仍有教材表述风险，例如把“光滑”作为无穷泰勒等式的充分条件、把未缩放的小批量求和梯度称为全量求和梯度的无偏估计。这些不是格式修复能自动保证正确的内容，不能称为已完成全面数学验证。
- 另提供本机 `round3/reviewed-notes.md` 核验副本，明确标注并修正上述问题、向量值导数的维度描述、凸最小二乘的初始化/局部极小点表述，以及多项式系数数量与次数的区别；保留 `notes.md` 原始输出供比较。核验副本不代表未来自动生成已能避免所有相同错误。
