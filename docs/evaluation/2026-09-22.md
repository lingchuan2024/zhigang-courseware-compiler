- 修复截断/非法 JSON 重试前的已计费响应未计入用量的问题；每次响应单独记录耗时，避免重复累计整段重试耗时。

- 加入真实 API 评估脚本，记录接口原始 usage、HTTP 状态、阶段耗时、知识结构和完整笔记；解析缓存按课件 SHA-256 区分。
- `pnpm check`、`pnpm lint`、`pnpm build` 通过。Lint 有 11 项现存警告，构建有大包警告。

运行方式：先在忽略目录 `.uploads/evaluation/credentials.json` 配置 `deepseek`、`mineru`，执行 `node scripts/evaluate-course.mjs <pdf> <label>`。第三个参数可指定已生成知识结构所在的运行标签，以便对同一结构只重跑笔记阶段。脚本复用应用的 MinerU 代理和生产生成函数。

真实调用进行中；后续轮次补充实测数值和内容评审。没有把自动结构覆盖率作为事实正确率。

## 第二轮：证据完整性与生成效率

真实运行发现 `topicsToCandidates` 将连续来源区间缩成首尾块，局部合并后的公式、例子与中间推导因此丢失。首跑只覆盖 19.79% 的原文块，尽管 57 张卡片均标为完成。修复后按同一文档展开完整区间，增加多次压缩、逆向区间和跨文档隔离的回归测试。

主题综合采用最多 3 个并发 worker，结果仍按学习顺序保存，章节写作仍按顺序运行。综合正文只输出到 `sections[].markdown`，章节输入不再重复携带同一正文的顶层 `markdown`；重试单章使用相同的精简输入。保留条件与 AI 补充标记，防止二次改写模糊材料边界。

529 项测试通过，类型检查、lint、生产构建通过。真实复跑沿用同一 MinerU 解析，从知识提取开始重跑，结果待补。
