# 三种课件的两轮迭代

目标：验证课件经过两层知识结构、知识卡片、课程母笔记之后，是否形成有依据、能独立学习的材料；不能把关联覆盖率或章节生成成功等同于事实正确。

## 样本与检查口径

| 样本 | 页数 | 主要内容 | 检查重点 |
| --- | ---: | --- | --- |
| 第五周第1讲—热学 | 45 | 平衡态、理想气体、统计规律与概率 | 稳恒态反例；混合气体物质的量；恒温气压公式的负号与前提；互斥与对立；概率密度和概率；涨落 |
| 第5周第1次-Python面向对象编程（一） | 38 | 类与实例、初始化、封装、访问限制 | 截图代码缩进与输出分离；实例方法与类方法；self 命名约定；名称改写；getter/setter 校验 |
| Lecture 5 Plagiarism and citing sources (2) | 28 | 引用、概括、转述、整合来源 | 40 词长引用阈值；10% 建议的适用范围；改写仍须引用；避免把改写等同于换同义词；练习中正确与错误案例的对应关系 |

完整 PDF 均来自用户指定的本地本科课件目录，没有裁页。原课件、解析文本、模型结果与凭据不进入 Git。用 `pdftotext` 辅助全文阅读，并渲染重点页面核对截图与公式；真实链路仍使用 MinerU 解析结果。

原始测评输出保存在忽略目录 `.uploads/evaluation/multi-{physics,python,writing}-{base,r1,r2}/`。其中 `notes.md` 是实际自动生成结果，不是人工润色稿。`requests.json` 记录提供商返回的 token（含截断和重试），`metrics.json` 记录阶段时间。MinerU 未返回 token 用量，不能算入 DeepSeek token 总量。

同轮样本有并行执行，网络与提供商排队会影响耗时；这是单次实测，不是统计显著的性能基准。Python 检查只解析代码语法，不运行模型生成代码；语法通过不代表运行行为正确。公式检查使用应用本身的 MarkdownRenderer，渲染成功也不代表公式语义正确。

## 基准发现

- Python：53 张卡片、4 章全部生成，但两个 Python 代码块无法解析：一个类方法缩进损坏，一个混入了控制台输出。MinerU 对截图的错误识别进入了笔记。
- Python：笔记重复把实例方法称为“类方法”，把 self 约定泛化为强制命名；类本身的对象身份、带默认值的初始化参数也需要更准确的限定。
- 原课件中存在需要解释的简写。修正必须注明依据或教学澄清，不能悄悄伪造成课件原话。

## 第一轮：原始证据与代码缩进

修复母笔记组装时按段落 trim 导致的代码缩进破坏；综合主题时重新提供去重、有预算上限的原始课件摘录，明确区分原始证据与派生卡片，并要求保留条件、分离代码与输出、标记澄清。测评脚本增加按阶段计费统计和跨课件缓存校验。

为了隔离笔记阶段的变化，本轮复用各自基准的解析与知识卡片，未重新生成知识结构。下表仅比较**笔记阶段**，不把缓存后的耗时冒充全流程提速。

| 课件 | 基准笔记秒数 → 第一轮 | 基准笔记 token → 第一轮 | 第一轮章节 | 结论 |
| --- | ---: | ---: | --- | --- |
| 热学 | 243.635 → 222.589 | 437,672 → 420,853 | 6/6 | 主题综合由 27 完成+1降级变为28完成；本轮无截断 |
| Python | 119.563 → 108.778 | 148,113 → 146,284 | 4/4 | 合并后完整保留代码章原稿，但模型本身仍输出2处代码语法错误 |
| 学术写作 | 209.584 → 185.776 | 311,528 → 303,661 | 6/6 | 章节规划更连贯，但姓氏大小写的错误解释仍被卡片传递到笔记 |

基准热学输出有 6 处 KaTeX 错误，来自引用块中公式行丢失 `>` 前缀；第一轮新输出恰好没有这些错误，不能据此认为根因已修复。第二轮需补回归测试和确定性修复。

源头问题：Python 的53张卡片、热学154张卡片、写作122张卡片中，很多节点只是同一概念的动机、定义、性质或同一示例的重复页。卡片拆分过细，造成重复和上下文割裂。英文第4页的 `not capitalized` 箭头实际指向页码缩写 `p.`，并非作者姓氏；第一轮仍复制了错误卡片。第二轮将重新生成知识结构和卡片。

第一轮验证：534项测试通过，类型检查与构建通过，lint无错误（11项既有警告）。详细原始计数见同目录 `multicourse-metrics.json`；各轮 `audit-original-renderer.json` 固定保留该轮渲染器的检查结果。
