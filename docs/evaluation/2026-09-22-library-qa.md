## 变更

- 检索记录归属于课件库文档 ID，原始解析文档 ID 保留在 sourceRanges。修复引用打开课件、按文档检索和删除索引的关联。
- IndexedDB v4 从已有课件快照重建相关索引，保留无关记录；无需重新调用模型处理课件。

- 模型没有提供合法引用时，拒绝将回答标记为课件证据；证据不足时允许无引用的说明，不再自动用前三个命中伪造引用。
- 修复 React StrictMode 重放 effect 时跳过索引加载的问题；显示课件与卡片覆盖数量。
